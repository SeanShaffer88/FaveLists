# Roadmap

Only real, planned work — nothing speculative.

## Done

- **v0.2 program** — command registry + JSON channel, undo/redo and
  the autosave journal, bulk actions, duplicate finder + merge,
  personal ratings and notes, share cards, CSV import.
- **v0.3 program** — tags and status, smart views and Pick for me,
  CSV/JSON export, paste-a-list import, barcode add, appearance
  options, trash with restore, automatic backups, update check,
  first-run wizard.
- **v0.4.0** — engineering-contract conformance: tier record,
  versioned data files with tested migration, static runtime,
  release checksums, standard docs set. No feature changes.

## Next

New feature work starts from the open field-test findings
([FIELD_TEST.md](FIELD_TEST.md)) — the areas still unverified on a
real Windows PC (trash restore, barcode lookup, cover flows) are
exercised first, and anything they shake loose is fixed before new
features are scheduled. No next feature program is planned yet.
