FaveLists — portable build
==========================

No install needed: unzip this folder anywhere and run the exe.

Your lists live in a FaveListsData folder created next to the exe, so
moving this folder (to another drive, or a USB stick) moves the whole
app and all your data together. Nothing is written anywhere else, and
there are no accounts, no sync, and no tracking.

The build is unsigned, so Windows SmartScreen may warn on first run —
choose "More info" -> "Run anyway".
